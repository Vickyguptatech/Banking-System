# 🏦 Banking System — Mini Project

A menu-driven **Python console application** that simulates real-world banking operations — account creation, secure login, deposits, withdrawals, transfers, transaction history, and PIN management — with data saved permanently using **JSON**.

## ✨ Features

| Feature | Description |
|---|---|
| 🆕 Create Account | Enter name, phone number & set a 4-digit PIN |
| 🔐 Login | Access account using Account Number & PIN |
| 💰 Check Balance | View current account balance |
| ➕ Deposit | Add money to your account |
| ➖ Withdraw | Withdraw money (with balance check) |
| 🔄 Transfer | Send money to another account |
| 📜 Transaction History | View all past deposits, withdrawals & transfers |
| 🔑 Change PIN | Securely update your PIN |
| 🚪 Logout | Return safely to the main menu |

All data is stored in **`accounts.json`**, so your accounts and transactions stay saved even after closing the program.

## 🚀 How to Run

```bash
python bank_system.py
```

Make sure `bank_system.py` and `accounts.json` (auto-created on first run) are in the same folder.
